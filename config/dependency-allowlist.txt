# Dependency allowlist — LumeMedLink (§8.8)
#
# EXACT GROUP NAMES, one per line. Never prefixes.
#
# This file used to hold prefixes, and the matcher used to accept any group that merely BEGAN with
# one. That is a hole in a class, not an instance, and it was measured rather than argued:
# `androidx.health.connect` — a CLINICAL DATA API, in the app whose whole identity is that it holds
# no clinical content — passed the gate green, together with `io.ktorexploit` and
# `org.jetbrainsevil`. The earlier bait rehearsal missed it because the bait names were unrelated
# (`net.evil.tracker`); a hostile name that shares a namespace with a real one is the one a human
# reviewer waves through, and it was exactly the one the gate could not see.
#
# So: adding a dependency now costs one exact line, and a namespace-adjacent name is a hard failure.
# A new group failing here is the gate WORKING — decide it, then add it (§13 wants its ADR).
#
# Regenerated 2026-08-21 from the real lockfiles (F20, ADR-0018).
